# macOS 微信标签批量操作

以下入口在 Mac 微信 4.1.15、2026-11-19 的一次百人规模操作中核对过。把这些名称作为寻找控件的线索，不把版本、布局或坐标当作永久不变的接口。

## 进入与新建

1. 进入“通讯录”，找到列表顶部的“通讯录管理”。该入口可能在 AX 摘要中只是一行空文字：此时读取当前完整窗口结构或截图，确认这一行的实际边界后点击。不要因文字搜索不到就判定 Mac 不支持，也不要保存本次屏幕坐标供下次复用。
2. 在“通讯录管理”左侧查看标签列表。虚拟列表只暴露可见行；滚动或在列表确实取得焦点后使用导航键。搜索框中的 End/Tab 可能只移动光标或输入空白，操作后要回读。
3. 已有目标标签时选中它并记录原人数与成员身份。没有时使用左侧“新建标签”，按当前编辑控件命名并回读。新建会先出现空名称或“未命名”；按 Escape 可能留下空标签，而不是撤销创建。
4. 命名控件未暴露时，已观察到标签右键菜单有“修改标签名”。另一条已实测的创建路径是：在管理表格中搜索一位确定好友，核实仅该结果，勾选后“设置标签”→“搜索或创建标签”→创建指定标签；收起弹层后等待保存，并核验原标签仍在。随后转入目标标签批量添加其他人。

上述备用路径的表格“全选”只在完整结果确实等于预期好友集合时使用；不要把管理页全选误当成单行选择。普通行文字还可能是备注编辑区域，点击行中心不一定会勾选。

## 标签右键与漏报的弹层

先左键选中目标标签，再右键打开菜单。“添加成员”“复制”“修改标签名”“删除标签”曾出现在独立菜单窗口中。

- 某些 UI 摘要只显示原管理窗口，即使菜单已经打开。若右键后摘要没变化，先读取完整窗口/菜单结构或当前截图，不能直接判定右键失败并连续点击。
- 使用当前环境允许的 UI 方法。可用的原生 AX 工具应枚举所有相关窗口，按菜单项角色、标题和非零边界定位；从运行时读到的位置派生点击，不硬编码屏幕位置。坐标输入仍须遵守当前工具的窗口原点和缩放约定。
- 同时安装 `wechat-find-friends` 时，可选用其 `wechat_ax_query.swift` 的 `dump` 辅助检查完整结构；本 skill 不依赖该工具。通用点击只用于当前已观察、已授权的具体动作，不把检索辅助工具当作任意写操作接口。
- 截图空白不是菜单不存在的证据，也不足以诊断“防截屏”。检查当前窗口、焦点与工具采集能力；已有“窗口 → 通讯录管理”菜单可用于返回本次窗口。
- 多份应用安装时核对实际运行路径，不凭 bundle ID 另开第二份客户端。不要重启微信、关闭别人的窗口或修改安全设置来修复定位。

选择“添加成员”后，确认打开的是标签成员选择器，而非“发起会话”或群聊成员选择器。

## 累计多选

此版本观察到的线索：窗口“微信添加成员”，搜索结果列表 ID `sp_search_result_list`，普通列表 ID `sp_to_select_contact_list`，底部“完成”按钮 ID `confirm_btn`。这些只是定位线索，还需结合从目标标签进入的导航上下文和当前界面核对。

每行按以下证据推进：

1. 在选择器搜索框输入准确备注；无匹配时可改用短姓名，把空格差异和 OCR 错字分开处理。
2. 采集当前结果并确认覆盖完整。短查询返回很多人时继续枚举；缺少 Value、首屏只有几人或滚动未生效，都不能推出不存在更多匹配。滚动无效时先核对焦点和列表，再用有依据的分页/导航方式；跳到末尾只检查了末尾，未覆盖中间。
3. 精确匹配仍有两个账号时，不按结果顺序、头像性别或昵称习惯猜人。展示当次头像或资料对照给用户；得到回答后重新查看，按回答对应的身份选择，不能永久记作“永远选第一项”。
4. 勾选前读当前状态，勾选后回读选中状态及人数。控件 Value 为 1 只代表当前勾选；禁用/无 Value 可能表示已在标签内，但须核实当前成员关系再登记 `already_member`。
5. 切换查询后确认已选人数保留。若人数归零或选择器消失，停止当前循环，重新读取状态，不把失去的选择当作保存成功。

操作循环只能从刚读取的结构派生下一步，遇到预期窗口、搜索词、状态或人数不符就退出循环。不要把一次会话的 JavaScript 控件索引写进 skill。

## 提交后的异步更新

点击“完成”后可能先显示“正在添加”，随后返回管理页并渐增人数。这是异步过程；在原操作仍更新时再次全量提交会使恢复变得不可靠。

记录提交时的目标标签、基线成员、本批确定账号和已选数。在合理观察期内读取人数与成员，直到稳定并与预期集合一致；不能仅因为过去若干秒就宣告成功。人数不足且已停止变化时，只读核查缺少的账号与错误提示，再决定是否补入已确认缺失者。结果不明则保留 `submitted_unconfirmed`。

清理只涉及本次明确创建的零成员占位标签。删除入口必须先确认当前选中的是该占位标签；不能从上一次标签位置推断，也不能改为删除联系人。清理后再次回到目标标签验收。
